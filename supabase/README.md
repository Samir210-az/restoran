# Supabase Qatı

Bu qovluq Faza 1-də boş saxlanılır (tələb olunduğu kimi, biznes məntiqi hələ yoxdur).

- `migrations/` — Faza 2-də verilənlər bazası cədvəlləri (SAD bölmə 5) buraya SQL migrasiya faylları kimi əlavə olunacaq.
- `functions/` — Edge Function-lar (SAD bölmə 7) buraya əlavə olunacaq.
- `seed/` — test/demo məlumatı.

Yerli inkişaf üçün: `supabase init` və `supabase start` Faza 2-nin əvvəlində işə salınacaq.
